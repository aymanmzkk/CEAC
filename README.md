# Ejercicios de Programación en Python · 1º DAM

Ejercicios de clase de 1º de DAM (CEAC FP Valencia) centrados en la **programación orientada a objetos en Python**.

## Contenido (`programacion/`)

- **Tipos de datos, constantes y métodos**
- **Clases y objetos:** clientes, cuenta bancaria, gatos y perros
- **Encapsulación:** propiedades privadas, getters y setters
- **Colecciones:** listas de teléfonos y agenda de contactos
- **CRUD** de clientes y aplicación de productos
- **Ficheros:** leer y escribir texto
- Primeros pasos con un **servidor web** en Python

**Tecnologías:** Python 3
